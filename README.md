# Legal pages

Privacy policies and terms for Pir Ahmed's apps, served with GitHub Pages at https://pirrahmed.github.io.

This repo contains only these public pages. No app source code lives here.

| App | Page | URL |
|---|---|---|
| Bedtime Companion | Privacy Policy | https://pirrahmed.github.io/bedtime-companion/privacy/ |

To add an app, create a folder named after it (for example `redraft/privacy/index.html` and `redraft/terms/index.html`) and link it from `index.html`.
